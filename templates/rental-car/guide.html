老闆如何自己改車款與照片

網站上所有車款都來自同一個檔案 cars.json。改這個檔案、存檔、上傳，網站就更新，不需要動任何程式。

一、改 cars.json（最簡單）

  1. 用記事本或 VS Code 打開 cars.json。
  2. 每台車是一組 { ... }，直接改裡面的文字或數字。
  3. 存檔後上傳到主機覆蓋舊檔，重新整理網頁即可。
{
  "id": "eco-01",
  "category": "國產代步車",
  "name": "Breeze 1.5 小型房車",
  "price_per_day": 1200,
  "specs": ["5 人座", "1.5L", "自動"],
  "best_for": "市區代步、出差",
  "image": "photos/breeze.jpg",
  "available": true
}
欄位說明
category分類，同名稱的車會自動歸在同一個篩選按鈕
price_per_day日租價，只填數字
image照片路徑或網址；留空會顯示示意插圖
availablefalse 會顯示「目前已出租」並停用詢價
注意：每組 { } 之間要有逗號，最後一組後面不要逗號；文字都要用英文雙引號。改壞時頁面會顯示友善提示而不是空白，可用 jsonlint.com 檢查格式。

二、換車款照片

  1. 把照片放進網站資料夾的 photos/（建議 1600×1000、小於 300KB、JPG 或 WebP）。
  2. 在該車款的 image 填 "photos/檔名.jpg"。

三、之後接 Google Sheet（免改 JSON）

  1. 建立試算表，第一列放欄位名稱（id、category、name、price_per_day、specs、best_for、image、available）。
  2. 「檔案 → 共用 → 發布到網路」，選分頁並選 CSV 格式，取得網址。
  3. 由開發者把 app.js 的 dataUrl 改成該網址，並加入約 20 行 CSV 轉換程式；specs 欄用「、」分隔。
  4. 之後老闆只要改試算表，網站幾分鐘內自動更新。

此為升級選項，作品集示意站目前使用 cars.json。

四、本機預覽備註

雙擊開啟 index.html 時，瀏覽器會擋讀檔，因此改讀 cars.fallback.js（cars.json 的複本）。要測試真正的 cars.json，請在資料夾內執行 python3 -m http.server 後開 localhost:8000。
